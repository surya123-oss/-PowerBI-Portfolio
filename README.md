**# Sales \& Retail Analytics Dashboard**



**## Project Overview**

**This project analyzes retail sales data using Microsoft Power BI to identify revenue trends, profitability, and regional performance.**



**## Tools Used**

**- Microsoft Power BI Desktop**

**- DAX**

**- CSV Dataset**



**## Dashboard Features**

**- Total Revenue**

**- Total Profit**

**- Total Orders**

**- Profit Margin**

**- Monthly Revenue Trend**

**- Revenue by Region**

**- Revenue by Product Category**

**- Profit by Region**

**- Interactive Region and Category Filters**



**## Dataset**

**The project uses a synthetic retail sales dataset containing 1,200 order-line records covering 2024–2025.**



**## Key Skills Demonstrated**

**- Data visualization**

**- Business intelligence**

**- DAX measures**

**- KPI reporting**

**- Interactive dashboard design**
